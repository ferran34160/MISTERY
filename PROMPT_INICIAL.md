# Què enganxar a Claude Code per continuar

1. Descomprimeix `misteri_v1.zip` en una carpeta (per exemple `misteri`).
2. Obre Claude Code en aquesta carpeta (així llegeix `CLAUDE.md` sol).
3. Enganxa això:

```
Llegeix CLAUDE.md i mira les captures de referencia/. Primer executa
`python prova.py` per comprovar que tot funciona al meu ordinador.
Després fes el pas 1 i el pas 2 de «Propers passos»: afegeix els objectes al
JSON i construeix la pàgina web per al mòbil (català i francès) que carregui
casos_prova.json. Pregunta'm només si hi ha una decisió que no es pot desfer.
No copiïs l'aspecte ni els textos del joc de referència.
```
